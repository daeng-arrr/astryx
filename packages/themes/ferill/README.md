# FERILL Theme

FERILL's semantic color and component styling layer for Astryx. It extends the
versioned Astryx Neutral theme and keeps FERILL product flows and content in the
FERILL application.

This package is intentionally private and is not published to npm. It is built
and versioned with the `daeng-arrr/astryx` fork. The `0.7.16-ferill.0` version
records the Astryx stable release used as its base.

## Build

From the Astryx repository root:

```sh
pnpm --filter @daeng-arrr/astryx-theme-ferill build
```

The generated JavaScript, CSS, and declaration files stay beside the theme
source. The package keeps the upstream Astryx MIT license and notices.
